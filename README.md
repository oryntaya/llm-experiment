# llm-experiment

Небольшие опыты с токенами и случайностью LLM.

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python exp1_tokenizer.py            # опыт 1, токенайзеры OpenAI
# опыт 1б (нужен ключ): pip install anthropic; export ANTHROPIC_API_KEY=...; python exp1b_claude_count.py
```

## Опыт 1. Токенизация одних и тех же текстов: EN, RU, RU латиницей, KK, KK латиницей

Скрипт: `exp1_tokenizer.py`. Тексты: `results/exp1_texts.json` (7 текстов по ~65–120 символов: приветствие, новость,
техническая фраза, литература, числа и даты, диалог). Английский, русский и казахский (кириллица) написаны вручную,
русский транслит и казахская латиница (алфавит 2021 г., акуты) получены транслитерацией кодом — вручную не писались.
Разбор по токенам: `results/exp1_details.md`, сводка: `results/exp1_summary.md`.

> Исправление: в первой версии опыта казахская латиница была записана вручную с опечаткой (`ásilin` вместо `tásilin`).
> Теперь все латинские варианты строит код, цифры изменились.

### Токенайзеры OpenAI (tiktoken 0.14.0)

| токенайзер | модели |
|---|---|
| r50k_base | GPT-3 |
| cl100k_base | GPT-3.5, GPT-4 |
| o200k_base | GPT-4o, GPT-4.1, o3, GPT-5, GPT-5.1 (по таблице tiktoken) |
| o200k_harmony | gpt-oss; тот же словарь, что o200k_base, + служебные токены |
| o200k_base (предположение) | **gpt-6-astra**, см. примечание ниже |

Примечание про gpt-6-astra: по сторонним сайтам (Vercel, OpenRouter и др.) модель вышла в сентябре 2026 года, но
tiktoken 0.14.0 её не знает (`encoding_for_model` падает), а официального описания токенайзера найти не удалось.
Единственная версия в источниках — o200k_base, и это НЕ проверено. Поэтому в таблицах она совпадает с GPT-4o/5
(en 136 / ru 181 / kk 210 токенов) автоматически, а не по замеру. Если у модели свой словарь, цифры будут другими:
для проверки нужен ключ OpenAI и подсчёт токенов в API (`usage.prompt_tokens`).

Выводы по OpenAI:
- Английский почти не меняется между поколениями (133 / 138 / 136 токенов). Всё улучшение — для других языков.
- Кириллица подешевела в разы: русский 671 -> 314 -> 181, казахский 749 -> 518 -> 210.
- На r50k и cl100k латиница выгоднее кириллицы (kk 518 против kk-lat 326 на cl100k). На o200k наоборот: кириллица выгоднее (ru 181 против ru-lat 249, kk 210 против kk-lat 290), потому что в словаре появились целые русские и казахские слова.
- На самом новом токенайзере русский стоит 1.33x английского, казахский 1.54x. Казахская латиница хуже всех — 2.13x.
- Транслит и латиница не дают выигрыша на современных токенайзерах: лучше всего родная кириллица.

### Токенайзеры Anthropic (Claude): точный замер не получен

У Claude нет локального токенайзера, а ключа API в окружении не было. Что сделано:

1. `exp1b_claude_count.py` — готовый скрипт для точного подсчёта через `count_tokens` (модели claude-sonnet-5-5, claude-opus-5-5, claude-haiku-5-5). Не запускался, нужен `ANTHROPIC_API_KEY`.
2. Косвенный замер через счётчик токенов субагентов Claude (`results/exp1b_claude_estimate.md`). Калибровка на тексте с известным числом токенов его НЕ подтвердила: на 296 слов совпало, на 400 и 900 слов завышено примерно на 150 токенов. Абсолютным цифрам верить нельзя.

Сырые данные (прирост над базовым замером, 3 повтора набора):

| модель | en | ru | ru-lat | kk | kk-lat |
|---|---|---|---|---|---|
| sonnet | 627 | 834 | 1074 | 1116 | 1224 |
| opus | 627 | — | — | 1116 | — |
| haiku | 749 | — | — | выброс | — |

Что можно сказать осторожно:
- Opus и Sonnet дали ровно одинаковые числа — возможно, общий токенайзер. Haiku на английском дал больше, но это может быть и особенностью замера.
- Отношения к английскому у Sonnet (ориентир): ru 1.33x, ru-lat 1.71x, kk 1.78x, kk-lat 1.95x. Порядок языков такой же, как у o200k: русский дешевле всех, казахская латиница дороже всех.
- Это ориентир, а не измерение. Для настоящих цифр запустите `exp1b_claude_count.py` с ключом.

## Опыт 2. Случайность: «Придумай название для кофейни» × 3

Результат: `results/exp2_randomness.md`. Три независимых запуска (три субагента Claude, у каждого чистый контекст).

- Всего названий 23, разных 15. «Ристретто» и «Крема» встретились во всех трёх ответах.
- Два чата из трёх выбрали «Зерно и Пар», третий — «Первая чашка».
- Вывод: есть устойчивое ядро ответов, случайность проявляется в хвосте списка и в итоговом выборе. Три запуска — иллюстрация, не статистика.
